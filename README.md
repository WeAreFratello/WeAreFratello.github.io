# WeAreFratello.github.io

Public pages for WeAreFratello's Android apps, served by GitHub Pages at
https://wearefratello.github.io/. The app repositories are private, so
anything that needs a public URL (privacy policies linked from Google Play)
lives here.

- `symptomtracker/privacy-policy.html`: Symptom Tracker privacy policy

Pages publish automatically when `main` is pushed. Keep each policy's
"Effective" date current when its content changes.
